# DD-023: Document Lifecycle State Machine

## Status: Retired
## Date: 2026-08-22

> **This design decision was retired during the August 2026 architecture overhaul.**
>
> DD-023 originally defined a document lifecycle state machine (draft → active → archived → superseded) with transition rules, cascading effects on the document graph, and editability constraints.
>
> Its concepts have been partially absorbed into:
> - **US 0.8** — Single Active Draft Lifecycle
> - **[DD-004](DD-004_editor_ux_patterns.md)** — Editor UX Patterns (editability constraints)
> - **[DD-020](DD-020_status_badge_design_system.md)** — Status Badge Design System
